# Тауарларды басқару жүйесі — OOP жобасы

Бұл жоба Python тілінде объектіге бағытталған бағдарламалау қағидаларын пайдаланып жасалған.

## Жобада қолданылған OOP принциптері

- **Инкапсуляция** — `Product` класындағы `__price` және `__quantity` жабық өрістері
- **Мұрагерлік** — `FoodProduct`, `ElectronicsProduct`, `ClothingProduct` кластары `Product` класынан мұра алады
- **Полиморфизм** — әр еншілес класс `info()` әдісін өзіне сәйкес қайта анықтайды
- **Объектілер** — әр тауар жеке объект ретінде құрылады

## Жобаның мүмкіндіктері

- жаңа тауар қосу;
- барлық тауарларды көру;
- атауы бойынша іздеу;
- тауар мәліметтерін өзгерту;
- тауарды өшіру;
- тауарды сату;
- қойма статистикасын көру.

## Іске қосу

Терминалда:

```bash
python main.py
```

командасын орындаңыз.
